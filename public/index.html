Toys API

Node.js + Express + MongoDB REST API — port 3001

Base URL

http://localhost:3001

Protected routes (POST / PUT / DELETE toys) require header x-api-key: YOUR_JWT_TOKEN. Get a token from POST /users/login.

Users

MethodRouteWhat it does
GET/usersHealth check for users router
GET/users/userInfoReturns the logged-in user (token required, password hidden)
POST/usersRegister. Password is hashed with bcrypt. Duplicate email returns an error. Role is always USER.
POST/users/loginLogin with email + password. Returns JWT token.

Register body

{
  "name": "Dana Cohen",
  "email": "dana@gmail.com",
  "password": "123456"
}

Login body

{
  "email": "dana@gmail.com",
  "password": "123456"

Toys

Pagination: ?skip=0 is page 1 (first 10 toys), ?skip=1 is page 2, and so on. Limit is always 10.

MethodRouteWhat it does
GET/toysList toys. Bonus filters: ?s= search, ?category=, ?min= & ?max=, plus ?skip=
GET/toys/search?s=ball&skip=0Search in name OR info
GET/toys/category/Outdoor?skip=0Toys by category
GET/toys/prices?min=10&max=40&skip=0Toys in a price range
GET/toys/single/:idOne toy as an object
GET/toys/countNumber of toys in the collection
POST/toysAdd toy. Token required. Server sets user_id from the token.
PUT/toys/:idEdit toy. Token required. Only owner or ADMIN.
DELETE/toys/:idDelete toy. Token required. Only owner or ADMIN.

Toy body (POST / PUT)

{
  "name": "Soccer Ball Size 4",
  "info": "Durable outdoor soccer ball",
  "category": "Outdoor",
  "img_url": "https://images.pexels.com/photos/47730/the-ball-stadion-football-the-pitch-47730.jpeg",
  "price": 25
}

Permissions

USERADMIN
Can add toys. Can edit/delete only toys whose user_id matches the token. Can add toys. Can edit/delete any toy.

צעצועים
